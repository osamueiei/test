Explore the intuition behind common supervised, unsupervised, neural-network and reinforcement-learning algorithms through lightweight interactive visualizations.

How to use

Each card contains a simplified visual model. Click Run, Shuffle, or move the controls to see the concept change.

  • Regression → predict a continuous value
  • Classification → choose a class
  • Clustering → discover groups
  • Neural networks → learn layered representations
  • RL → learn actions from rewards
