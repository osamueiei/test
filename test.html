01

Linear Regression

Supervised · Regression · Least Squares

ลากเส้นตรงเส้นเดียวให้ผ่านกลุ่มข้อมูลโดยให้ผลรวมของ "ระยะห่างแนวตั้งยกกำลังสอง" น้อยที่สุด เส้นสีส้มคือ residual ของแต่ละจุด — คลิกบนกราฟเพื่อเพิ่มจุดแล้วดูเส้นขยับ

คลิกบนพื้นที่กราฟ = เพิ่มจุดข้อมูล
—

สมการ

ŷ = w·x + b
Loss = Σ(y − ŷ)² / n

หาค่า w, b ยังไง

ใช้สูตรปิด (closed form) จาก covariance ÷ variance หรือใช้ gradient descent ก็ได้ผลเดียวกัน

ใช้ตอนไหน

ทำนาย "ตัวเลขต่อเนื่อง" เช่น ราคาบ้าน ยอดขาย และใช้เป็น baseline ก่อนลองโมเดลซับซ้อน

ข้อควรระวัง

ไวต่อ outlier มาก จุดหลุดจุดเดียวดึงเส้นทั้งเส้นได้ ลองคลิกเพิ่มจุดไกล ๆ ดู

โค้ด scikit-learn
# ทำนายค่าต่อเนื่องด้วยเส้นตรง
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X_train, y_train)
print(model.coef_, model.intercept_, model.score(X_test, y_test))
02

Logistic Regression

Supervised · Classification · Sigmoid

เอาเส้นตรงมาผ่านฟังก์ชัน sigmoid เพื่อบีบผลลัพธ์ให้อยู่ในช่วง 0–1 แล้วอ่านเป็น "ความน่าจะเป็นของคลาส" เฉดสีพื้นหลังคือความมั่นใจของโมเดล ยิ่งซีดแปลว่ายิ่งลังเล

คลิก = เพิ่มจุดคลาสที่เลือก · โมเดลเทรนต่อทันที
—

สมการ

z = w₁x₁ + w₂x₂ + b
p = 1 / (1 + e⁻ᶻ)

Loss

Binary Cross-Entropy: −[y·log p + (1−y)·log(1−p)] ลดด้วย gradient descent

จุดเด่น

ตีความง่าย ค่าน้ำหนักบอกได้ว่าฟีเจอร์ไหนดันไปทางคลาสใด เร็วมากและเป็น baseline มาตรฐาน

ข้อจำกัด

เส้นแบ่งเป็นเส้นตรงเสมอ ถ้าข้อมูลพันกันเป็นเกลียวต้องพึ่ง kernel หรือ neural net

โค้ด scikit-learn
from sklearn.linear_model import LogisticRegression
clf = LogisticRegression(C=1.0, max_iter=1000).fit(X_train, y_train)
proba = clf.predict_proba(X_test)[:, 1]  # ความน่าจะเป็นของคลาส 1
03

k-Nearest Neighbors

Supervised · Instance-based · ไม่มีการเทรน

kNN ไม่ "เรียน" อะไรเลย มันจำข้อมูลทั้งหมดไว้ พอมีจุดใหม่เข้ามาก็ดูเพื่อนบ้านที่ใกล้ที่สุด k ตัวแล้วโหวต — เลื่อนเมาส์บนกราฟเพื่อดูว่าใครคือเพื่อนบ้านของจุดนั้น

เลื่อนเมาส์/นิ้ว = ยิงจุดทดสอบ
—

ระยะทาง

d = √Σ(xᵢ − qᵢ)²

k เล็ก vs k ใหญ่

k=1 เส้นแบ่งหยักมาก จำ noise (overfit) · k ใหญ่ เส้นเรียบขึ้นแต่กลืนรายละเอียด (underfit)

ต้องทำก่อนเสมอ

สเกลฟีเจอร์ให้เท่ากัน ไม่งั้นฟีเจอร์ที่หน่วยใหญ่จะครองระยะทางทั้งหมด

ต้นทุน

เทรน 0 วินาที แต่ทำนายช้าเพราะต้องวัดระยะกับทุกจุด ไม่เหมาะกับข้อมูลใหญ่มาก

โค้ด scikit-learn
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
X = StandardScaler().fit_transform(X)  # สำคัญมากสำหรับ kNN
clf = KNeighborsClassifier(n_neighbors=5).fit(X_train, y_train)

Decision Tree

Supervised · Gini Impurity · Axis-aligned splits

ต้นไม้ถามคำถามทีละข้อ เช่น "x < 0.42 ไหม" แล้วแบ่งข้อมูลเป็นสองฝั่ง เลือกคำถามที่ทำให้แต่ละฝั่ง "บริสุทธิ์" ที่สุด เส้นแบ่งจึงตั้งฉากกับแกนเสมอ ทำให้เกิดลายบล็อกแบบนี้

ซ้าย = พื้นที่ตัดสินใจ · ขวา = โครงต้นไม้
—

เกณฑ์แบ่ง

Gini = 1 − Σ pᵢ²
เลือก split ที่ Gini ลดมากสุด

ลองเลื่อนดู

ลึก 1–3 เส้นแบ่งเรียบง่าย พอลึก 6–7 จะเริ่มเกิดบล็อกเล็ก ๆ ล้อม noise รายจุด นั่นคือ overfitting เห็น ๆ

จุดเด่น

อธิบายให้คนทั่วไปเข้าใจได้ ไม่ต้องสเกลข้อมูล รับทั้งตัวเลขและหมวดหมู่

จุดอ่อน

ไม่เสถียร เปลี่ยนข้อมูลนิดเดียวโครงต้นไม้เปลี่ยนหมด — เป็นที่มาของ Random Forest ในแผ่นถัดไป

โค้ด scikit-learn
from sklearn.tree import DecisionTreeClassifier, plot_tree
clf = DecisionTreeClassifier(max_depth=3, criterion="gini").fit(X, y)
plot_tree(clf, filled=True)

Random Forest

Supervised · Bagging · Ensemble

ปลูกต้นไม้หลายต้น แต่ละต้นเห็นข้อมูลคนละชุด (bootstrap) แล้วให้โหวตกัน ต้นเดียวเส้นแบ่งจะแข็งเป็นบล็อก พอรวมหลายต้นขอบจะนุ่มลงเพราะเป็นสัดส่วนคะแนนโหวต — เลื่อนจำนวนต้นไม้ดูความต่าง

ความเข้มของสี = สัดส่วนต้นไม้ที่โหวตคลาสนั้น
—

ความสุ่ม 2 ชั้น

1) สุ่มตัวอย่างแบบมีคืนที่ (bootstrap) 2) สุ่มฟีเจอร์ที่ใช้พิจารณาในแต่ละ node

ทำไมถึงดีขึ้น

Var(ค่าเฉลี่ยของ T ต้น) ≈ Var / T
(เมื่อต้นไม้ไม่สัมพันธ์กัน)

โบนัส

ได้ feature importance และ out-of-bag score ฟรีโดยไม่ต้องแยก validation set

แลกมาด้วย

เสียความ "อธิบายได้" ของต้นไม้เดี่ยว และไฟล์โมเดลใหญ่ขึ้นตามจำนวนต้น

โค้ด scikit-learn
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=300, max_depth=None,
                            oob_score=True, n_jobs=-1).fit(X, y)
print(rf.oob_score_, rf.feature_importances_)

Support Vector Machine

Supervised · Max-margin · Hinge Loss

SVM ไม่ได้หาเส้นแบ่ง "เส้นไหนก็ได้" แต่หาเส้นที่มี ช่องว่างกว้างที่สุดระหว่างสองคลาส จุดที่มีวงกลมล้อมคือ support vector — มีแค่จุดพวกนี้ที่กำหนดเส้น จุดอื่นถอดออกได้เลย

เส้นทึบ = decision boundary · เส้นประ = ขอบ margin
—

เป้าหมาย

min ½‖w‖² + C·Σ max(0, 1 − yᵢ·f(xᵢ))

C คืออะไร

C ต่ำ = ยอมให้จุดหลุดเข้ามาในช่องได้ margin กว้าง · C สูง = บังคับให้ถูกทุกจุด margin แคบและเสี่ยง overfit

Kernel trick

ถ้าข้อมูลแยกด้วยเส้นตรงไม่ได้ ใช้ RBF kernel ยกไปมิติสูงแล้วค่อยตัดด้วยระนาบ

เหมาะกับ

ข้อมูลมิติสูงแต่ตัวอย่างไม่เยอะ เช่น ข้อความ หรือข้อมูลชีวสารสนเทศ

โค้ด scikit-learn
from sklearn.svm import SVC
clf = SVC(kernel="rbf", C=1.0, gamma="scale").fit(X, y)
print(clf.support_vectors_.shape)

K-Means Clustering

Unsupervised · Lloyd's Algorithm

ไม่มีเฉลย ไม่มี label — อัลกอริทึมสลับทำสองอย่างวนไป: จับทุกจุดเข้าศูนย์กลางที่ใกล้ที่สุด แล้วย้ายศูนย์กลางไปกลางกลุ่มของตัวเอง กดเดินทีละรอบเพื่อดูศูนย์กลางค่อย ๆ ไถลเข้าที่

กากบาท = centroid · เส้นจาง = เส้นทางที่ centroid เคลื่อนมา
—

ค่าที่พยายามลด

Inertia = Σ ‖x − μ_c(x)‖²

เลือก k ยังไง

วาดกราฟ inertia เทียบ k แล้วหา "ข้อศอก" (elbow) หรือใช้ silhouette score ช่วยตัดสิน

จุดอ่อน

ผลขึ้นกับตำแหน่งเริ่มต้น (จึงมี k-means++) และชอบกลุ่มทรงกลมขนาดพอ ๆ กันเท่านั้น

ใช้จริงกับ

แบ่งกลุ่มลูกค้า ย่อสีภาพ บีบอัด vector และทำ feature engineering

โค้ด scikit-learn
from sklearn.cluster import KMeans
km = KMeans(n_clusters=3, init="k-means++", n_init=10).fit(X)
labels, centers = km.labels_, km.cluster_centers_

MLP — Multilayer Perceptron

Supervised · Backpropagation · Non-linear

ซ้อนชั้นเชิงเส้นคั่นด้วยฟังก์ชันไม่เชิงเส้น (tanh) เครือข่ายก็ดัดเส้นแบ่งได้อิสระ ข้อมูลรูปเกลียวนี้ logistic regression ทำไม่ได้เลย แต่ MLP ค่อย ๆ พันเส้นแบ่งตามได้ — ดูแผนภาพขวาประกอบ เส้นหนา = น้ำหนักมาก

ซ้าย = decision boundary · กลาง = โครงข่าย · ขวา = loss
—

Forward

h = tanh(W₁x + b₁)
ŷ = σ(W₂h + b₂)

Backward

ไล่ chain rule จาก loss ย้อนกลับไปทุกน้ำหนัก แล้วขยับสวนทาง gradient

ลองสังเกต

hidden 2 ตัวมักติดอยู่ที่เส้นตรงหัก ๆ พอเพิ่มเป็น 12–16 ถึงจะพันเกลียวได้ครบ

ต่อยอด

เพิ่มชั้น เปลี่ยนเป็น ReLU ใส่ dropout / batch norm ก็กลายเป็น deep learning สมัยใหม่

โค้ด PyTorch
import torch.nn as nn
model = nn.Sequential(nn.Linear(2,16), nn.Tanh(),
                      nn.Linear(16,16), nn.Tanh(),
                      nn.Linear(16,1))
loss_fn, opt = nn.BCEWithLogitsLoss(), torch.optim.Adam(model.parameters(), 1e-2)

CNN — Convolutional Neural Network

Deep Learning · Convolution → ReLU → Pooling

หัวใจของ CNN คือเลื่อนหน้าต่างเล็ก ๆ (kernel) ไปทั่วภาพแล้วคูณ-บวก ได้ feature map ที่ตอบสนองต่อลวดลายบางอย่าง เช่น ขอบแนวตั้ง — วาดบนตารางซ้ายด้วยเมาส์ได้เลย แล้วดูผลลัพธ์เปลี่ยนสด ๆ

ลากบนภาพอินพุตเพื่อวาด · คลิกขวา/ลากพร้อม Shift เพื่อลบ
—

การคำนวณ

out(i,j) = Σₘ Σₙ in(i+m, j+n) · K(m,n)

ทำไมไม่ใช้ MLP

CNN ใช้น้ำหนักร่วมกันทั้งภาพ (weight sharing) พารามิเตอร์น้อยลงมหาศาลและทนต่อการเลื่อนตำแหน่ง

ReLU + Pooling

ReLU ตัดค่าลบทิ้ง เหลือแต่การตอบสนองเชิงบวก แล้ว max-pool 2×2 ย่อขนาดครึ่งหนึ่งเพื่อสรุปใจความ

ของจริง

ในโมเดลจริง kernel ไม่ได้ตั้งเอง แต่ถูก เรียนรู้ จากข้อมูล และซ้อนกันหลายสิบชั้น

โค้ด PyTorch
import torch.nn as nn
cnn = nn.Sequential(
    nn.Conv2d(1, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Flatten(), nn.Linear(64*7*7, 10))

LSTM — Long Short-Term Memory

Deep Learning · Sequence · Gated Memory

RNN ธรรมดาลืมเร็วเพราะ gradient หายไประหว่างย้อนเวลา LSTM แก้ด้วย "สายพานความจำ" (cell state) ที่มีประตูสามบานคอยควบคุมว่าจะลืมอะไร รับอะไรเข้า และปล่อยอะไรออก — ดูแถบประตูขยับตามแต่ละ time step

บน = ลำดับอินพุต · ล่างซ้าย = ค่าประตู · ล่างขวา = ความจำ c และเอาต์พุต h
—

สามประตู

f = σ(Wf·[h,x]) ลืม i = σ(Wi·[h,x]) รับเข้า o = σ(Wo·[h,x]) ปล่อยออก

อัปเดตความจำ

c = f⊙c_prev + i⊙tanh(g) h = o ⊙ tanh(c)

ทำไมถึงจำได้ยาว

c เดินทางผ่านการคูณ-บวกตรง ๆ ไม่ผ่านฟังก์ชันบีบซ้ำ ๆ gradient จึงไม่ถูกบีบจนหาย

ใช้กับ

อนุกรมเวลา เสียงพูด ข้อความ และ ลำดับแพ็กเก็ตในทราฟฟิกเครือข่าย

โค้ด PyTorch
import torch.nn as nn
lstm = nn.LSTM(input_size=1, hidden_size=64, num_layers=2, batch_first=True)
out, (h_n, c_n) = lstm(x)          # x: (batch, seq_len, features)
pred = nn.Linear(64, 1)(out[:, -1])  # ใช้ step สุดท้ายทำนาย

Transformer — Self-Attention

Deep Learning · Attention · ประมวลผลขนานทั้งลำดับ

แทนที่จะไล่อ่านทีละคำแบบ LSTM ทุกคำมองเห็นทุกคำพร้อมกัน แล้วให้ "คะแนนความสนใจ" กันเอง ตารางคือ attention matrix — แถวคือคำที่กำลังมอง คอลัมน์คือคำที่ถูกมอง ยิ่งเข้มยิ่งสนใจมาก

เลื่อนเมาส์บนตารางหรือบนคำ เพื่อดูเส้นเชื่อมความสนใจ
—

สมการหลัก

Attention(Q,K,V) = softmax(QKᵀ / √d_k) · V

Multi-head

ทำหลายหัวขนานกัน แต่ละหัวจับความสัมพันธ์คนละแบบ เช่น หัวหนึ่งจับไวยากรณ์ อีกหัวจับคำอ้างอิง

Positional encoding

attention ไม่รู้ลำดับเองเลย ต้องบวกสัญญาณตำแหน่งเข้าไปใน embedding ก่อน

ข้อแลกเปลี่ยน

เร็วเพราะขนานได้เต็มที่ แต่หน่วยความจำโตแบบ O(n²) ตามความยาวลำดับ

โค้ด PyTorch
import torch, torch.nn.functional as F
scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)
attn   = F.softmax(scores, dim=-1)
out    = attn @ V
# หรือใช้สำเร็จรูป: nn.MultiheadAttention(embed_dim, num_heads)

Reinforcement Learning — Q-Learning

Reinforcement · Trial and Error · Temporal Difference

ไม่มีชุดข้อมูลเฉลย มีแต่รางวัล เอเจนต์เดินสุ่มไปเรื่อย ๆ ชนกับดักก็โดนหักคะแนน ถึงเป้าก็ได้แต้ม แล้วค่อย ๆ อัปเดตตาราง Q สีในช่องคือค่าที่เรียนได้ ลูกศรคือนโยบายที่ดีที่สุด ณ ตอนนี้

เขียว = เป้าหมาย +1 · แดง = กับดัก −1 · เทา = กำแพง
—

กฎอัปเดต

Q(s,a) ← Q(s,a) + α[ r + γ·max Q(s',a') − Q(s,a) ]

Explore vs Exploit

ε สูง = เดินสุ่มเยอะ เจอทางใหม่แต่ช้า · ε ต่ำ = รีบใช้ทางที่รู้แล้ว เสี่ยงติดทางที่ไม่ดีที่สุด

γ (discount)

บอกว่าให้ค่ากับรางวัลอนาคตแค่ไหน ใกล้ 1 = มองยาว ใกล้ 0 = เอาแต้มเฉพาะหน้า

ต่อยอด

ถ้าสถานะเยอะเกินจะเก็บเป็นตาราง ก็ให้ neural net ประมาณค่า Q แทน → Deep Q-Network

โค้ด Q-Learning
Q = np.zeros((n_states, n_actions))
for ep in range(episodes):
    s = env.reset()
    while not done:
        a = env.sample() if rand() < eps else Q[s].argmax()
        s2, r, done = env.step(a)
        Q[s, a] += alpha * (r + gamma * Q[s2].max() - Q[s, a])
        s = s2

XGBoost — Gradient Boosting

Supervised · Boosting · เรียนจากความผิดพลาด

ต่างจาก Random Forest ที่ปลูกต้นไม้พร้อมกันแล้วโหวต — boosting ปลูก ทีละต้นตามลำดับ โดยต้นใหม่มีหน้าที่แก้ส่วนที่ต้นก่อนหน้าทำพลาด (residual) เลื่อนจำนวนรอบเพื่อดูเส้นทำนายค่อย ๆ เข้ารูป

บน = ค่าทำนายรวม · ล่าง = residual ที่เหลือให้ต้นถัดไปแก้
—

สูตรสะสม

F₀ = ค่าเฉลี่ย Fₘ = Fₘ₋₁ + η · hₘ(x) hₘ ฟิตกับ residual ของ Fₘ₋₁

learning rate

η ต่ำต้องใช้รอบเยอะแต่ได้ผลนุ่มและ generalize ดีกว่า η สูงเข้าเป้าไวแต่กระตุกและ overfit ง่าย

ทำไม XGBoost ชนะบ่อย

ใส่ regularization ในสูตรโดยตรง ใช้ second-order gradient จัดการ missing value เองและขนานได้

สังเกต

ตั้งรอบ 80 กับ lr สูง ๆ เส้นจะเริ่มไล่ตาม noise ทีละจุด นั่นคือสัญญาณว่าควรใช้ early stopping

โค้ด XGBoost
import xgboost as xgb
model = xgb.XGBClassifier(n_estimators=500, learning_rate=0.05,
                          max_depth=6, subsample=0.8,

Stacking Ensemble

Supervised · Meta-learning · รวมโมเดลต่างชนิด

Bagging รวมโมเดลชนิดเดียวกัน แต่ stacking รวม คนละชนิด แล้วให้โมเดลชั้นบน (meta-learner) เรียนรู้เองว่าควรเชื่อใครมากกว่าในสถานการณ์ไหน สามช่องเล็กคือ base model ช่องใหญ่คือผลรวมสุดท้าย

สามช่องซ้าย = base models · ช่องขวา = meta-learner
—

ขั้นตอน

1) เทรน base models ด้วย cross-validation 2) เก็บคำทำนาย out-of-fold เป็นฟีเจอร์ใหม่ 3) เทรน meta-learner บนฟีเจอร์นั้น

กฎเหล็ก

ต้องใช้คำทำนาย out-of-fold เท่านั้น ถ้าใช้คำทำนายจากข้อมูลที่ base เคยเห็น meta จะได้ข้อมูลรั่วและมั่นใจเกินจริง

เลือก base ยังไง

เอาโมเดลที่ผิดคนละแบบ เช่น tree + kNN + linear ยิ่งผิดไม่เหมือนกัน ยิ่งรวมแล้วได้กำไร

meta ควรเรียบง่าย

นิยมใช้ logistic regression เพราะถ้า meta ซับซ้อนเกินจะ overfit คำทำนายของ base ทันที

โค้ด scikit-learn
from sklearn.ensemble import StackingClassifier
stack = StackingClassifier(
    estimators=[("knn", KNeighborsClassifier(7)),
                ("tree", DecisionTreeClassifier(max_depth=5)),
                ("svm", SVC(probability=True))],
    final_estimator=LogisticRegression(), cv=5).fit(X, y)

หมายเหตุการจัดกลุ่ม: หน้านี้เรียงลำดับตามใบงาน ในทางวิชาการ CNN / LSTM / Transformer ถือเป็นสถาปัตยกรรม deep learning ที่ปกติเทรนแบบ supervised (หรือ self-supervised) ส่วน K-Means เป็น unsupervised แท้ ๆ — บนหน้าเว็บจึงจัดกลุ่มตามความเป็นจริงไว้ในแถบเมนู เผื่ออาจารย์ถาม
