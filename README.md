# Machine Learning Algorithm Visualizer

One-page HTML visualization for common machine learning algorithms.

## Included
1. Linear Regression
2. Logistic Regression
3. kNN
4. Decision Tree
5. Random Forest
6. SVM
7. K-Means
8. MLP (Neural Network)
9. CNN
10. LSTM
11. Transformer
12. Reinforcement Learning
13. XGBoost
14. Stacking

## GitHub Pages
1. Create a GitHub repository, for example `test`.
2. Upload `test.html` (and optionally `README.md`).
3. Commit to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and folder **/(root)**, then Save.
7. Open:
   `https://YOUR_USERNAME.github.io/test/test.html`

For example, if the GitHub username is `ph1loz`:
`https://ph1loz.github.io/test/test.html`
